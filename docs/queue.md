# Bounded queue module

PipeWireAO 4.0.9 ships the queue and discard sink with its native SDK.
The module name, queue properties and discard SPA factory name are stable.
See the [native queue contract and configuration](https://github.com/DarrylGamroth/PipeWireAO/blob/v4.0.9/docs/queue.md).
Earlier releases remain available for applications pinned to the standalone queue.
